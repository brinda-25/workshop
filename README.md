## 🛠️ Installation & Setup

Set up a local environment to execute notebooks and scripts.

### 1. Clone the Repository
```bash
git clone https://github.com/brinda-25/workshop.git
cd workshop
```

### 2. Configure Virtual Environment
Keep dependencies isolated using a Virtual Environment:

```bash
# Create the environment
python -m venv venv

# Activate it (macOS/Linux)
source venv/bin/activate

# Activate it (Windows Command Prompt)
# venv\Scripts\activate.bat
```

### 3. Install Dependencies
Run the installation steps to fetch the numeric, data-science, and plotting libraries:
```bash
pip install -r requirements.txt
pip install -r requirements-local.txt
```

### 4. Launch Jupyter Notebook
```bash
jupyter notebook
```
This command starts a local server. Open the local address in your web browser and navigate to any of the `.ipynb` files.
